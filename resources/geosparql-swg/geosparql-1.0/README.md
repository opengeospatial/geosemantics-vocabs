# GeoSPARQL 1.0

This directory contains the RDF resources for [GeosPARQL 1.0](http://www.opengis.net/doc/IS/geosparql/1.0).

## Use

These resources are not recommended for use since this version of GeoSPARQL has been superseded. 

See <https://www.ogc.org/standards/geosparql/> for the latest version of GeoSPARQL or look in other folders in this repository.


## Contact

For all issues to do with these resources, please contact the GeoSPARQL SWG at via [details on its main repo](https://github.com/opengeospatial/ogc-geosparql/#contact).
